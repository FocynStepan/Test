## 1. Контрольні запитання

### Чим відрізняється вебсайт від вебзастосунку?

* **Вебсайт:** Це переважно набір статичних сторінок, головна мета яких — надання інформації (наприклад, блог чи сайт-візитка).
* **Вебзастосунок:** Передбачає тісну взаємодію з користувачем, обробку даних та складну реакцію системи на дії (наприклад, онлайн-банкінг або соціальна мережа).

### Які етапи життєвого циклу вебпроєкту є критичними для UX/UI дизайнера?

Критичними етапами є:

* **Аналітика та UX:** Дослідження користувачів, створення User Stories та проектування логіки.
* **UI дизайн:** Пошук візуального стилю та відмальовка макетів.
* **Експорт ресурсів:** Підготовка іконок та графіки для розробників.
* **Design QA:** Перевірка реалізованої верстки на відповідність макету ("Pixel Perfect").

### У чому полягає цінність прототипування?

* Дозволяє протестувати рішення на реальних користувачах без написання коду.
* Заощаджує час та бюджет, оскільки виправлення помилок на етапі дизайну значно дешевше, ніж на етапі програмування.
* Наочно демонструє логіку переходів між екранами.

### У чому різниця між UX Researcher та UI Designer?

* **UX Researcher (Дослідник):** Фокусується на цифрах та психології. Проводить інтерв'ю, будує карти шляху користувача (CJM) та тестує гіпотези. Він не малює картинки.
* **UI Designer (Візуалізатор):** Відповідає за естетику: кольори, типографіку, сітки та емоційний відгук інтерфейсу.

### Різниця між Frontend та Backend простими словами

* **Frontend:** Це "обличчя" сайту — те, що ми бачимо в браузері (скелет — HTML, шкіра — CSS, м'язи — JS).
* **Backend:** Це "мозок" та серверна частина, яка прихована від очей, але саме вона обробляє дані та змушує сайт працювати.

## 2. Питання на дослідження

### SDLC на прикладі розробки мобільної гри

1. **Ідея та Аналітика:** Визначення жанру гри та цільової аудиторії.
2. **UX-дизайн:** Проектування ігрових механік, керування героєм (UX).
3. **UI-дизайн:** Створення концепт-артів, інтерфейсу меню та іконок.
4. **Програмування:** Написання коду на ігровому рушії.
5. **Тестування:** Пошук багів та перевірка ігрового балансу (QA).
6. **Деплой:** Реліз гри в App Store або Play Market.

### Роль UX/UI дизайнера в життєвому циклі вебпроєкту

| Етап SDLC | Роль дизайнера |
| --- | --- |
| **Аналітика** | Збір інформації, аналіз конкурентів, створення портрета користувача |
| **UX етап** | Побудова схем, вайрфреймів та логіки переходів |
| **UI етап** | Створення візуального стилю, вибір шрифтів та кольорів |
| **Розробка** | Експорт ресурсів та "архітектурний нагляд" за версткою |
| **Тестування** | Design QA — перевірка відповідності верстки макету |

### Поняття T-shaped skills для ІТ-спеціаліста

Сучасний ідеал — це **T-shaped фахівець**:

* **Вертикальна лінія (I):** Глибока експертиза в основній професії (наприклад, написання коду на C# або Python чи UI-дизайн).
* **Горизонтальна лінія (—):** Базові знання в суміжних сферах: розуміння UX-дизайну, основ маркетингу, емпатія та навички комунікації.

### Порівняння вакансій (Djinni / Work.ua)

| Навичка (Hard Skill) | UI/UX Designer | Web Designer |
| --- | --- | --- |
| **Основний інструмент** | Figma (компоненти, Auto Layout) | Figma, Adobe Photoshop, Illustrator |
| **UX Дослідження** | Обов'язково (CJM, User Flows) | Бажано, але не критично |
| **Прототипування** | Складні інтерактивні прототипи | Статичні макети або прості анімації |
| **Знання коду** | Розуміння Box Model, HTML/CSS | Часто вимагається знання конструкторів (Tilda/Webflow) |
| **Фокус роботи** | Логіка, зручність, бізнес-метрики | Візуальний стиль, графіка, лендінги |
